3.3.3 TYPE II ERROR, POWER AND SAMPLE SIZE
=======================================================
j) Practically meaningful difference Delta = 100,000 USD, alpha = 0.05
   Assumptions: two-sided z-approximation, sample variances s1^2, s2^2 used as
   the true variances, and the current group sizes n1, n2 for the power calculation.
   SE of the difference = $87,785.28;  Delta / SE = 1.139
   beta = P(Type II error) = Phi(z_a/2 - Delta/SE) - Phi(-z_a/2 - Delta/SE)
   beta (Type II error probability): 0.7932
   Power = 1 - beta: 0.2068

   Required sample size for power 0.90 (equal n per group)
   n = (z_a/2 + z_b)^2 * (s1^2 + s2^2) / Delta^2
     = (1.960 + 1.282)^2 * (1,255,232,816,100 + 116,695,172,010) / 100,000^2
   Required n per group: 1442
   (This formula ignores the far rejection tail, which is negligible here.)
   Interpretation: with the current samples the test detects a 100,000 USD difference with probability 21% only; about 1442 houses per group are needed to reach 90%.
